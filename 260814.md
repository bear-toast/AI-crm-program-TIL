## Field Service 담당 — 전체 착수 순서

### Phase 1 · 스키마

|#|작업|확인|
|---|---|---|
|1-1|Work Order Record Type 2종 생성|Label 한글 / **Developer Name 영문** (Flow 참조)|
|1-2|커스텀 필드 6개 생성|아래 표 참조. `Related_Order__c`는 Order 활성화 선행|
|1-3|페이지 레이아웃 2종 분리|설치 타입에는 승인 필드 제외|

**커스텀 필드**

```

WOLI.Is_Billable__c            Picklist              무상 / 유상

Product Consumed.Chargeable__c            Checkbox
```

### Phase 2 · Picklist 점검 ★

**Milestone·Flow가 값 문자열을 참조하므로 여기가 틀리면 전체가 안 돕니다.**

|#|대상|값|확인|

|2-1|`Work Order.Status`|New / Dispatched / In Progress / On Hold / Completed / Cannot Complete / Closed / Canceled|커스텀 값 추가 시 **StatusCategory 매핑 필수**|
|2-2|`Work Order Line Item.Status`|New / In Progress / Completed / Cannot Complete / Canceled|코디-08 다일차 진행 확인의 원천|
|2-3|`Service Appointment.Status`|None / Scheduled / Dispatched / In Progress / Completed / Cannot Complete / Canceled|**표준값 유지 권장** — FSL 내부 로직 참조|
|2-4|`Work Order.Priority`|긴급 / 보통 / 낮음|**Case.Priority와 값이 정확히 일치**해야 함 (복사 Flow)|

**2-4와 2-6이 조율 대상입니다.** Case 담당(Service)과 값 문자열을 정확히 맞추셔야 미러 Flow가 동작합니다. 띄어쓰기 하나만 달라도 실패합니다.

|지점|상대|내용|

## 권한 설정

FSL 제공 권한 세트는 **Field Service 객체**(Work Order, SA, Service Resource 등) 위주입니다. Case와 Asset은 표준 객체라 별도 권한이 필요합니다.

## 프로필 vs 권한 세트

Standard User 프로필을 복제하면 Case·Asset 기본 접근이 대개 포함되어 있는데, **CRUD 수준이 우리 시나리오와 안 맞습니다.**

프로젝트 고유 권한 세트를 만드시는 게 정확합니다.

```
압축성장_현장엔지니어
압축성장_코디네이터
```

## Field-Level Security가 더 중요합니다

객체 권한보다 **필드 단위 통제**가 핵심입니다.

**현장 엔지니어 — Case에서 편집 가능한 필드**

```
Approval_Status__c          승인 대행 입력
Customer_Approver__c        승인자 지정
Field_Approved_By_Proxy__c  대행 체크
Approved_At__c              자동 기록
```

**나머지 Case 필드는 읽기 전용**으로 두세요. 엔지니어가 우선순위나 보증 판정을 바꾸면 안 되니까요.

**현장 엔지니어 — Asset에서 편집 가능한 필드**

```
SerialNumber
InstallDate
Status
Replaced_Asset__c    (3막 세대 연결)
```

`Total_Runtime_Hours__c`, `Price` 같은 건 읽기 전용이 맞고요.

## 정리

```
프로필              최소 권한 (로그인·앱 접근)
FSL 권한 세트        Work Order · SA · Service Resource 등
프로젝트 권한 세트    Case · Asset · Product2 등 표준 객체 + FLS
```

**3층 구조**입니다. FSL 것만 붙이면 배차 화면은 열리는데 Case를 못 열고, 프로필만으로는 FSL 객체가 안 보입니다.

## 담당 조율

권한 세트는 공용 영역(D 담당)인데, 어드민 권한 있으시니 만드셔도 됩니다. 다만 **Case FLS는 Service 담당과 합의**하셔야 합니다 — 미러 필드 7개를 엔지니어에게 어디까지 열지가 그쪽 설계와 얽히니까요.
